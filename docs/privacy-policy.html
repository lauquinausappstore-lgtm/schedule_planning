DAYLINE · PRIVACY POLICY

隱私權政策

生效及最後更新日期：2026 年 11 月 16 日

本政策說明 Dayline 彩雲行程 Android 應用程式如何處理資料，適用於應用程式識別碼 com.hkaiSolveAcademy.vibeCoding.Cindy 的目前版本。開發者：Cindy；專案維護帳戶：lauquinausappstore-lgtm。

你的行程，留在你的裝置。

Dayline 不要求註冊帳戶，不會將你的行程傳送至開發者伺服器，也不含廣告、分析或追蹤 SDK。

1. 應用程式處理哪些資料

當你使用 Dayline 時，你輸入的行程標題、日期、開始及結束時間、類別、事件標記和備註，以及你選擇的顯示篩選和排列設定，會儲存在裝置內的應用程式私人儲存空間。這些資料用於顯示、編輯及整理你的行程，並保留顯示設定。

目前版本不要求你提供姓名、電郵地址、電話號碼或帳戶資料，不存取定位、聯絡人、相片、相機、麥克風或系統日曆，也不收集廣告識別碼或裝置追蹤資料。

2. 資料收集、傳送與分享

目前版本不要求網際網路權限，沒有開發者營運的後端或雲端同步功能。開發者不會透過應用程式接收你的行程或顯示設定，也不會出售、出租或向第三方分享這些裝置內資料。

3. 儲存、安全及保留期間

資料保留在 Android 為應用程式提供的私人儲存空間，直到你刪除個別事件、清除應用程式資料或解除安裝。應用程式設定為停用 Android 自動備份。裝置安全仍取決於你的螢幕鎖定、作業系統及裝置設定；請妥善保護裝置，避免在備註中輸入不必要的敏感資料。

4. 查看、更改及刪除資料

  • 在 Dayline 中點選事件，即可查看、修改或刪除該事件。
  • 如要刪除全部本機資料，可前往 Android「設定 → 應用程式 → Dayline → 儲存空間」，選擇清除資料，或解除安裝應用程式。選項名稱可能因裝置而異。
  • 清除資料或解除安裝後，應用程式沒有雲端副本可供還原。Dayline 不設帳戶，因此沒有另行刪除帳戶的程序。

5. 兒童使用

目前版本不設帳戶或資料上傳功能，開發者不會透過應用程式向兒童收集個人資料。家長或監護人可協助兒童管理裝置及刪除本機行程。

6. 此政策網頁及外部服務

本政策網頁由 GitHub Pages 託管，沒有加入自訂分析、廣告、追蹤程式或聯絡表格。當你瀏覽此網頁、下載檔案或開啟 GitHub 連結時，GitHub 可能依其政策處理網路請求資料，例如 IP 位址及技術記錄。詳情請參閱 GitHub 隱私權聲明。這與應用程式內的本機行程儲存分開處理。

7. 政策更新

如果應用程式的資料處理方式改變，我們會更新本頁及上方日期。如日後加入資料收集、分享或雲端功能，會在推出相關版本時說明。

8. 聯絡開發者

如對 Dayline 的隱私或資料處理有疑問，可透過 GitHub 專案問題回報聯絡維護者。GitHub 問題回報屬公開內容，請勿張貼私人行程、密碼或其他敏感資料。
