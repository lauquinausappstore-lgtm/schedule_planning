Dayline is a native Android schedule planner. Add a date and time, choose a category and an event marker, then decide how your schedule appears. The current app interface uses Traditional Chinese; this guide includes the matching labels.

About this documentation

This guide describes the updated project in this workspace. These changes have not been installed on your tablet or published to the original GitHub repository.

01 / GET GOING

Your first plan, in three steps

  1. Pick a day.

    Tap a date on the month calendar. Use the arrows to change months or 今天 to return to today.

  2. Add an event.

    Tap ＋ 新增事件. Enter its title, start and end time, category, marker and optional notes.

  3. Make the view yours.

    Under 顯示方式, choose which categories and markers to show, and how to order the results.

02 / YOUR EVENTS

Create, edit and delete

A title is required. The end time must be later than the start time on the same day. Overlapping events are allowed.

Add a plan

Choose 新增事件, complete the form and tap 儲存. Chinese titles and notes are supported.

Change a plan

Tap its event card, update any field, then save. You can change its date, category and marker.

Delete a plan

Open the card, tap 刪除 and confirm. Choose 保留 to cancel the deletion.

03 / SORT OUT THE DETAILS

One category. One marker.

Every event has a category and a marker. They answer different questions: what part of your life is this, and what needs your attention?

Event categories · 事件類別
App labelMeaningExample
生活LifeA dental appointment
工作WorkA client meeting
娛樂EntertainmentA film with friends
重要 · Important

A plan you want to give special attention.

緊急 · Urgent

A plan that needs prompt attention.

一般 · Normal

An everyday plan. This is the default.

These are three mutually exclusive markers, not separate three-level importance and urgency scales. Older events default to 一般. Legacy Work events become 工作; other old English categories become 生活.

04 / SEE WHAT MATTERS

Choose how your schedule appears

事件類別 · Category
Show all categories or just 生活, 工作 or 娛樂.
事件標記 · Marker
Show all markers or just 重要, 緊急 or 一般.
日期範圍 · Date range
Choose 選定日期 for the selected day, or 所有日期 to include every saved date, including past events.
排列方式 · Order
日期 sorts by date and start time. 重要優先 puts important events first; 緊急優先 puts urgent events first. Ties are ordered by date and start time.
Filters work together

Choose 工作 + 緊急 to see only urgent work events. Display settings are remembered. Calendar dots also follow your category and marker filters. Filtering never deletes an event.

05 / ON YOUR TABLET

Install Dayline on Android

Download Dayline 1.0 APK ↓

Requires Android 8.0 or newer. Download the APK on your Android device, open it, and allow your browser or file manager to install apps when Android prompts you. Follow the installation prompts, then open Dayline.

Release details

Install from Android Studio over USB

  1. On your tablet, enable Developer options by tapping Build number seven times in Settings. The exact Settings location varies by device.
  2. Enable USB debugging, connect a data-capable USB cable, and unlock the screen.
  3. Accept the tablet’s Allow USB debugging prompt for this computer.
  4. In Android Studio, select the tablet, choose the app run configuration and press Run.

For macOS, the project also includes Install-on-tablet.command. Run it from Finder or Terminal. It builds the current project, installs the debug APK and opens Dayline. If several devices are connected, it asks for a serial number.

The installer needs Android Studio, Platform-Tools and a working Gradle setup. First-time dependency downloads require internet. Installation has not been verified on the Lenovo tablet from this workspace.

06 / FOR DEVELOPERS

Open the Android Studio project

  1. Open the Dayline folder containing settings.gradle.kts. Do not open its parent folder or only the app folder.
  2. Install Android SDK Platform 36. Use JDK 17 or a compatible Android Studio bundled JDK.
  3. Wait for Gradle Sync to complete.
  4. Select the shared app run configuration, select a device, then Run or Debug.

07 / WHEN SOMETHING GETS STUCK

Troubleshooting

“Module not specified” when debugging

Finish Gradle Sync, then open Run → Edit Configurations → app. Select the Android application module ending in .app. If no module is listed, fix Gradle Sync errors first and confirm you opened the Dayline project root.

The tablet does not appear or says “unauthorized”

Unlock it, enable USB debugging and accept the authorization prompt. Check the cable supports data transfer and reconnect it. Install Platform-Tools through Android Studio’s SDK Manager if ADB is missing.

ADB reports “Operation not permitted”

The agent session previously blocked ADB’s USB access and local server. Run the installer in a normal macOS Terminal session, or use Android Studio on the computer.

No events appear

Set both category and marker to 全部, then choose 所有日期. A plan outside the selected date or filters is hidden, not removed.

The app cannot read saved plans

Changes are disabled to protect the stored data. Recover the saved data before clearing app storage. Clearing storage permanently removes the local plans.

08 / GOOD TO KNOW

Your plans stay on your device

Events are saved in the app’s private local storage. No account, backend or network permission is required. Android backup is disabled. Clearing storage or uninstalling Dayline removes its saved plans.

Dates and times use local wall-clock values and do not shift when you change timezones. This version supports one-time, same-day events; it does not include recurring events, reminders, cloud sync or system-calendar integration.
